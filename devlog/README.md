# Devlog

The devlog is the historical, human-oriented, non-normative record of the project: useful events, review evidence, context and limitations. Agents may consult it for history, but it does not override `docs/`, `governance/`, frozen specifications and contracts or current decisions. Current product documentation belongs in `docs/`; repository operating instructions belong in [governance](../governance/README.md). The [rationale guide](../governance/RATIONALE.md) is explanatory rather than an event log.

The [conventions](CONVENTIONS.md) own entry authoring, the date formats and timestamp provenance. This README indexes the recorded history.

## Recorded transitions

No transition has been recorded yet. When a project-state transition is worth keeping, add one dated entry file beside this index and list it here, newest last, with a one-line description. Continuity requires every entry to be indexed here and to carry the metadata the conventions name.
